ОБЪЕКТЫ — версия 0.4.2

Продолжение существующего GK-objects. Локальная база objectsSurveyDB версии 1 сохранена.
Все фото объекта скачиваются ZIP прямо из карточки и из общей галереи.
Есть резервное копирование/восстановление, архив и сохранение без адреса.

Supabase GK-objects создан 11 сентября 2026. URL, публичный ключ и команда
настроены в cloud-config.js. Таблицы и закрытое хранилище созданы.
Доступ к данным получают только пользователи, внесённые администратором в gk_members.
Учётные записи сотрудников пока не созданы. Реальный вход и обмен фото через HTTP
между смартфонами пока не проверены; до проверки не считать синхронизацию полностью готовой.

Проверено: локальные сценарии и модель двух устройств; SQL в настоящем Supabase
(сохранение, версии, конфликт, изоляция команды и отказ анонимному вызову).
Supabase security advisors после исправления прав: замечаний нет.
Для свежего развёртывания файл migrations/202609100001_gk_sync.sql включает обе стадии:
gk_sync и gk_private_functions. На действующем проекте обе уже применены.
Не применять их повторно.
