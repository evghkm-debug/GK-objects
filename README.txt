ОБЪЕКТЫ — MVP 0.2

Что добавлено по сравнению с 0.1:
- настоящая карта объектов (OpenStreetMap + Leaflet);
- кнопка «На карте» в карточке объекта;
- более понятный прогресс обследования;
- на этапе видно, сколько обязательных фото сделано;
- кнопка «Далее» заблокирована, пока не сделаны обязательные фото;
- подписи к уже сделанным фотографиям;
- нижнее меню скрывается во время обследования;
- блок «Что ещё уточнить»;
- быстрый статус объекта;
- более простой блок геопозиции при создании объекта;
- обновлён service worker, чтобы новые версии быстрее подхватывались.

ВАЖНО:
База IndexedDB сохранена с тем же именем и версией, поэтому при обновлении файлов GitHub Pages существующие объекты и фотографии в том же браузере должны сохраниться.

Обновление GitHub Pages:
1. В репозитории открыть Code.
2. Add file -> Upload files.
3. Загрузить с заменой: index.html, app.js, styles.css, sw.js, manifest.webmanifest и при желании README.txt.
4. Commit changes.
5. Закрыть установленное приложение полностью и открыть снова. При необходимости обновить страницу один раз.
