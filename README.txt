ОБЪЕКТЫ — обновление 0.4.1

Продолжение действующего приложения evghkm-debug/GK-objects v0.3.0.
База objectsSurveyDB, версия 1, и существующие объекты/фото сохранены.
Архив восстановленной v0.3.1 с другой базой не используется.

Добавлено:
- сохранение карточки без обязательного адреса;
- исправлено отложенное автосохранение при выходе с этапа;
- скачивание отдельного фото, системная отправка и ZIP всех фото;
- восстановление JSON без перезаписи отличающихся объектов;
- архивирование вместо удаления объектов;
- подготовлены вход и общая база Supabase с закрытыми фотографиями;
- очередь локальных изменений, повторная отправка, версии и сохранение конфликтующих копий.

В этой ветке облако ещё не подключено: cloud-config.js содержит пустые настройки.
Локальные функции работают без подключения. Живые записи пользователя не переносились.
Подготовка общей базы описана в supabase/SETUP.md.

При обновлении нужно сохранить все файлы приложения и vendor/jszip.min.js.
Сначала на каждом телефоне сохранить JSON-копию через кнопку ⇩.
Сайт и данные телефона не переносить на другой адрес без отдельной миграции.

Фото выгружаются в качестве, которое уже хранится в приложении (до 1280 px).
Скачивание не гарантирует автоматическое добавление снимка в системную галерею.
При потере связи синхронизация продолжится при открытом приложении после восстановления сети.

Проверки: cd tests; npm install; npm test.
Тесты используют изолированные хранилища и PostgreSQL PGlite; реальных записей там нет.
