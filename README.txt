ОБЪЕКТЫ — MVP 0.1

Что уже работает:
- добавление объекта;
- GPS-координаты с телефона;
- список и карточка объектов;
- 7-шаговый чек-лист обследования;
- обязательные фото по заданным ракурсам;
- съёмка камерой телефона;
- сжатие фото перед сохранением;
- автоматическое сохранение прогресса;
- продолжение обследования позже;
- итоговый статус;
- галерея фото по этапам;
- резервная копия данных в JSON;
- PWA: после размещения на HTTPS можно установить на главный экран телефона;
- офлайн-кэш интерфейса.

ВАЖНО ПРО ДАННЫЕ В ЭТОЙ ВЕРСИИ
Данные и фото хранятся локально в браузере телефона (IndexedDB). Для первого теста это удобно и бесплатно.
Не очищайте данные браузера без резервной копии. На экране «Объекты» кнопка ⇩ создаёт JSON-резервную копию.

КАК ЗАПУСТИТЬ НА КОМПЬЮТЕРЕ
1. Распакуйте папку.
2. Откройте терминал в папке.
3. Выполните: python -m http.server 8080
4. Откройте: http://localhost:8080

Простое открытие index.html двойным кликом тоже покажет интерфейс, но PWA/service worker и часть браузерных функций могут быть ограничены.

КАК ЗАПУСТИТЬ НА ТЕЛЕФОНЕ
Для камеры/GPS/PWA лучше разместить папку на бесплатном HTTPS-хостинге (например Vercel/Netlify/Cloudflare Pages/GitHub Pages). Это следующий шаг.
