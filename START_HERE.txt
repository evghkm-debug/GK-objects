ЗОЛОТОЙ КЛЮЧИК — ПОДКЛЮЧЕНИЕ ОБЩЕЙ БАЗЫ, 0.4.2

GitHub подключён, обновления публикует разработчик. ZIP вручную загружать не требуется.
Сайт: https://evghkm-debug.github.io/GK-objects/
Фото: открыть карточку → «Скачать все фото (...) одним ZIP».

Supabase создан, серверная схема и закрытый бакет gk-photos настроены.
Проект: https://supabase.com/dashboard/project/pbdigykrdteedaafbruo
Команда: Золотой Ключик.

Осталось владельцу:
1. Открыть проект Supabase → Authentication → Users.
2. Создать пользователя через Add user → Create new user (если названия отличаются,
   прислать скрин). Указать свою почту и собственный пароль. Если предлагается
   Auto Confirm User, включить. Приглашение по почте не требуется.
3. Не присылать пароль. Сообщить разработчику только адрес созданной учётной записи.
4. Разработчик проверит пользователя и добавит его в gk_members, выдавая доступ команде.
   Пока этой записи нет, вход не даёт доступа к объектам.
5. Администратору отключить свободную регистрацию новых пользователей в настройках Auth.

После выдачи доступа:
На каждом телефоне сначала сохранить JSON-копию через ⇩ в списке объектов.
Не очищать данные сайта. Обновить приложение до v0.4.2.
Открыть ☁ и войти в учётную запись команды.
Перенести прежние локальные объекты соответствующей кнопкой после резервного копирования.
Проверить объект и фото на втором телефоне; сверить контакты и площади.
Офлайн-изменения передаются при открытом приложении после восстановления сети.
При конфликте обе версии сохраняются для сверки.

Тестовые SQL-данные удалены откатом транзакции. Пользовательских записей в облаке пока нет.
Реальные камера, вход и загрузка фото через HTTP ещё требуют проверки.
